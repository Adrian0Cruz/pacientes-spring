# Patient Management API

API REST independiente para la gestión de pacientes, construida como práctica de fundamentos backend. 

## Tecnologías
- Java 21
- Spring Boot 3
- Spring Data JPA & Validation
- PostgreSQL
- Docker & Docker Compose
